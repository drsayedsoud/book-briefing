        مفتاح Gemini API

        لتوليد ملخصات لأي كتاب تريده

        يمكنك الحصول على مفتاح API مجاني تماماً خلال 30 ثانية من منصة Google AI Studio.

        ملاحظة أمان: يُحفظ المفتاح داخل متصفحك الشخصي فقط (LocalStorage)، أو يمكنك ضبطه في متغيرات بيئة Vercel (GEMINI_API_KEY) عند نشر التطبيق.

        كيف ترفع التطبيق على GitHub و Vercel؟

        خطوات بسيطة للحصول على رابط مباشر يشتغل فوراً

        1 إنشاء مستودع على GitHub

        اذهب إلى github.com/new وأنشئ مستودعاً جديداً باسم book-briefing (اختره Public).

        2 رفع الأكواد من سطر الأوامر (Git Commands)

        نفذ هذه الأوامر في مجلد المشروع:

        git init
        git add .
        git commit -m "Initial commit of Book Briefing App"
        git branch -M main
        git remote add origin https://github.com/اسم_حسابك/book-briefing.git
        git push -u origin main
        3 الربط والنشر على Vercel
        1. سجل دخول إلى vercel.com باستخدام حساب GitHub.
        2. اضغط "Add New" ثم "Project".
        3. اختر مستودع book-briefing واضغط Import.
        4. في قسم Environment Variables أضف:
          Key: GEMINI_API_KEY
          Value: مفتاحك من Google AI Studio
        5. اضغط Deploy، وخلال 15 ثانية ستحصل على رابط حي مباشر (مثل: book-briefing.vercel.app)!
